# Device Maintenance release status

The current stable backend release is `2026.10.1`.

Release flow:

```text
dev → beta → main
```

Stable releases are published from `main`. Beta prereleases are published from `beta`. Development builds on `dev` are not published through HACS.

The historical pre-calendar beta line ended at `0.1.0-beta.6`.

The Device Maintenance Card remains separately distributed from the backend integration. The current tested frontend is `0.2.0-dev.11`.

See [Installation](docs/installation.md), [Release notes and beta history](docs/beta-notes.md), [Development and release flow](docs/development.md), and [Migration plan](docs/migration.md).
